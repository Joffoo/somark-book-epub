# 出版级排版修润与样式规范 (Editorial Guidelines)

本文档定义 `somark-book-epub` 在对 SoMark 解析出的 Markdown 进行二次编辑、精修时遵守的通用出版级排版契约。适用于单人专著、文集、小说、学术论著与翻译文学。

---

## 1. 标题层级系统与小节规范 (Heading Hierarchy)

### 1.1 章节大标题与体例锚定
- 物理切片对应逻辑章节，每个切片顶部确立为**唯一的二级标题**：
  ```markdown
  ## 篇章标题
  ```
- 若原标题因艺术字排版被 OCR 误断为多行，必须合并为单行完整标题。
- **篇章独立署名**（仅多作者文集/特稿期刊适用）：若章节具备独立作者或译者，紧随 `## 篇章标题` 之后标为：
  ```html
  <p class="chapter-author">作者名</p>
  ```
  单作者专著或长篇小说不在正文重复标注章节作者。

### 1.2 篇内小节降级与独立序号提级
- **篇内小节降级**：篇目正文内所有小节统一设为三级标题 `### 小标题`，不得出现同级 `##`。
- **独立序号提级律**：
  - 图书常使用独立成行的汉字数字（`一`、`二` ... `十四`）、罗马数字（`I`、`II`）或阿拉伯数字（`1`、`1.1`）作为分节标志；
  - Agent 通读时必须感知篇章分节体例，将这类独立序号统一提级为三级标题：
    ```markdown
    ### 一
    ```
- **空行规范（CommonMark 语法）**：
  - 每一个标题行（`##`、`###`）的前后必须严格保留一个空行，严禁与正文段落紧贴粘连。

## 2. 插图与图题语义绑定 (Figure & Caption Contract)

SoMark 原始输出中方括号内为 AI 视觉描述，真实印刷图题位于图片下方。Agent 必须执行语义绑定：

### 2.1 绑定动作准则
1. **具有原书图题时**：
   - 图片下方紧随简短对象性说明（通常 $\le 35$ 字，如“清代铜胎掐丝珐琅香炉。”、“实验装置俯视示意图。”）；
   - 将图题文字提取填入方括号，**并在正文中彻底删除该单行文字**：
     ```markdown
     ![清代铜胎掐丝珐琅香炉。](images/part_01_fig_02.jpg)
     ```
   - Pandoc 将自动编译为出版级语义容器：`<figure><img ... /><figcaption>图题</figcaption></figure>`。
2. **纯场景/装饰图（下方无图注）时**：
   - 方括号留空：`![](images/part_01_fig_01.jpg)`，下方文字按正常正文流式排版。
3. **图文唯一性原则**：
   - 每张图片在章节中仅出现一次，严禁在正文和附加容器内重复引用同一张图片。

## 3. 通用出版容器与块级元素 (Universal Blocks)

- **篇首/篇尾题记与献词**：
  ```html
  <div class="epigraph">
  “是科学，亦是演化之光印刻在大地上的诗。”
  </div>
  ```
- **文献引用与长引文**：使用标准 Markdown 块引用语法：
  ```markdown
  > 引文正文内容...
  ```
- **边栏说明与案语盒**：
  ```html
  <aside class="callout">
  编者注或背景说明文字...
  </aside>
  ```

## 4. 数字化去噪标准 (Universal De-noising)

纸质图书转化为数字典藏本时，必须剔除实物印刷工业物料，保留纯净阅读内容：

### 4.1 必须剔除的印刷工业物料
- **版权页 CIP 数据**：图书在版编目数据、核字号、ISBN 注册信息、出版发行单位工商地址；
- **印刷实物标识**：条形码扫描图片、防伪水印、定价、印张、印数、开本与装帧形式说明；
- **纸书物理扫描残留**：页眉（Running header）、页脚、物理页码、跨页连字符断行。

### 4.2 必须完整保留的阅读价值内容
- 封面图（作为全书封面元数据绑定）；
- 题记、献词、凡例、导读、作者自序、译者序；
- 正文全部章节、附录、编后记、阅读计划与致谢。

---

## 5. 流式正文与注释系统 (Typography & Footnotes)

- **正文流式段落**：
  - 中文自然段落平滑连贯，段落之间空一行；
  - 清理 OCR 带来的段内误换行与行尾反斜杠 `\`。
- **脚注双向弹框**：
  - 正文引用保持 `[^1]`，文末定义保持 `[^1]: 注释内容`；
  - `chapter_assembler.py` 会自动注入章节专属前缀（如 `[^c01_1]`），杜绝全书交叉跳转冲突。
- **随文夹注**：括号随文注直接保留在正文中，不强行剥离为脚注。
